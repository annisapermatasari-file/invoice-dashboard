# Invoice Dashboard UI

High-fidelity Invoice Dashboard UI mockup built with React + Tailwind CSS + lucide-react.
Standalone project extracted from `Dasboard-Medsos-Kursus`, using mock data only (no backend).

## Development

```bash
npm install
npm start
```

## Build

```bash
npm run build
```

Deploys as a static site (e.g. on Vercel) with zero configuration — Create React App is auto-detected.
